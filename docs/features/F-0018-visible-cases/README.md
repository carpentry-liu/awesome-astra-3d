# F-0018 · 移除不可查看的案例与失效媒体

用户要求所有上架案例都能查看效果；没有可查看效果的条目移除。基线 7fda631，工作区干净。

## 方案

1. 继续保留仅有原帖的条目，依赖访问者跳转外站：不能满足直接查看效果的要求，不采用。
2. 对全部封面与站内录像读取真实响应并验证媒体类型；仅保留存在可验证效果图或完整录像的案例，移除失败的资源。采用。演示和原帖作为补充，不再用文字占位充当可见效果。

数据移除保存于不参与网站构建的审核档案，记录原因；原始视频附件不删除。数据、README、目录、统计同步更新。新增收录检查阻止无效果图、无录像条目再次进入主库。播放器加载失败时撤下空播放器并展示同一作品效果图，保留完整文件下载入口。

## 实施与验证

- 全库 303 个独立媒体 URL：读取响应前 64 KiB 并检查图像/MP4 标识，300 成功、3 个 Reddit 预览返回 403。不能把 HTTP 200 的 HTML 当作媒体。
- 下架 37 条：34 条没有站内效果图/录像，3 条预览失效且没有归档录像。部分有外站演示的条目仍暂时下架，待补齐可显示预览再恢复。完整原记录与原因见 `docs/archive/unlisted-cases-2026-09-25.json`。
- 104 个原演示入口复查，4 个请求失败；其中 1 个所属案例已下架，其余 3 个从保留案例中移除。HTTP 可达不代表独立试玩通过。
- 本地浏览器检查页对全部 97 段线上 MP4 执行 loadeddata、静音播放时间推进、时长比较、跳转末尾：97/97 通过。另对保留的 204 张图片执行完整加载与 naturalWidth 检查：204/204 通过。记录在 `data/media-audit.json`；不是每一帧全量解码。
- 修复 video 使用 source 子元素时错误事件不能可靠抵达 video 的问题：播放 URL 改为 video.src，由 video.onError 切换为作品效果图。取消重复的外站“观看视频”按钮；10 条无归档录像的“完整运行录像”标签移除，封面标明静态。
- 更新后的 `observedAt` 表示本次媒体核查；来源日期、收录日期、模型证据级别保持不变。
- `npm run check`：204 条数据、11 项测试与 TypeScript 通过；清理前新规则已拒绝无预览案例。
- `npm run build`：204 条目录、README 统计与静态导出通过，9 项首页资源引用通过。既有大包与 DEP0190 警告保留。
- 本地播放器加载 Cabsolutely：readyState 4、640 px、26.218667 秒，无媒体错误；站点控制台 warning/error 为空。桌面列表 0 空预览、0 已完成加载的坏图。

验证覆盖全库媒体响应、视频容器、既有测试、类型检查、构建、桌面/手机浏览器与控制台。HTTP 媒体探测不等于所有网络永远可达，浏览器播放需要另外验证。Git 可回滚，ChatGPT Sites 不部署。
