# 实施

实施日期：2026-10-02（Asia/Shanghai）。关联 [R-0002](../../requirements/R-0002-catalog-growth.md)，采用 [02-设计](02-设计.md) 的构建时静态页方案。

## 作品发现与材料入口

首页保留既有墨黑、亮蓝与大图展示风格，将六件稳定编辑精选与日常新增分开。精选为鹈鹕骑车、Orbital Core、梵高小镇、Jelly Baby、Jetis 工厂及五个三维故事；图片直接使用事实源中的原作者媒体地址，不在本轮下载第三方媒体。

三条材料路线分别连接 Blender、GLB 网页和浏览器游戏上手文档，四个专题连接 Blender、浏览器游戏、建筑与数字孪生、机械拆解。作品旁展示可取得的材料，GitHub 入口明确标为 Star 收藏，不增加催促弹窗。

手机实拍发现百分比 Grid 将六件精选挤为窄列；改为不换行 Flex，各卡片占容器 80% 且禁止收缩，以容器横向滚动保持效果图和标题可读。页面本身不产生水平溢出。

中英文导航、筛选、资源说明和入口文案由 `src/i18n.ts` 管理；来源原文与未公开提示词保持原有语义。首页以 `?lang=en` 进入英文，静态作品和专题采用独立 `/en/` 路径。

## 真实链接与原生浏览器操作

资源和最新入口的真实 `href` 包含分组、资源、排序及必要重置，普通点击、复制链接和修改键打开采用同一目标。语言切换保留当前筛选、传播参数和 hash。

独立复核发现两处空查询链接问题：清空筛选只用 hash 会沿用原查询；从英文切回中文只给空查询也可能保留 `lang=en`。入口使用 `./#collection`，语言切换增加 `./` 路径前缀，确保浏览器重新解析 pathname 与 query；单测加入这两项原生地址解析检查。

普通点击仍在首页完成滚动或打开详情；卡片提供静态作品页作为修改键、新标签、复制地址及未完成交互增强时的目标。既有 `#case=` 地址保留兼容，hash 与浏览器历史变化同步详情选择。

## 轻量索引与按需详情

`data/cases.json` 继续作为唯一事实源。`scripts/catalog-index.mjs` 提取首页搜索和卡片必需字段，输出可追踪的 `data/catalog-index.json`；完整证据、提示词与媒体下载字段保留在完整记录中。检索仍覆盖全部 237 条记录的既有搜索字段，Astra 与方法参考默认分别呈现。

首页首批渲染 36 条匹配卡片，按操作继续加载；筛选与排序变化重置展示数量。详情按案例 ID 请求 `./case-data/<id>.json`，核对返回 ID 与记录结构，缓存成功结果；过期请求通过 AbortController 取消。读取失败展示实际失败状态及静态作品入口，不以缩略索引冒充已取得完整证据。

`npm run catalog` 同步轻量索引、237 份完整 JSON、公开全量 JSON、中英 README 自动统计与最新八条，以及更新目录和 sitemap。统计仍区分 225 条 Astra、12 条方法参考、59 个源码 / 工程入口、88 个演示入口及 110 段完整视频。

## 静态详情、专题与可抓取目录

`scripts/generate-case-pages.mjs` 从事实源生成 474 个中英作品详情、8 个专题及 14 个分页目录。各页提供真实标题、canonical、OG/Twitter 封面与语言对应地址；作品详情展示原作者、来源等级、日期、公开材料与权利说明。

所有事实文本与属性进行 HTML 转义；来源及媒体仅允许 HTTP(S) 地址。日期和提示词缺失时显示未公开 / 未核实，参考作品在详情和目录明确排除 Astra 计数。英文页仅对实际中文来源文本标注中文语言，避免把英语录像标签及缺失提示误标为中文。

公开情况、观察结果与模型来源的 27 种内部状态映射为双语读者说明，作者自由文本仍保留原文；未识别状态继续显示未公开 / 未核实。

同站媒体按当前页面深度生成相对链接，中文详情录像为 `../../videos/...`，英文详情为 `../../../videos/...`，保留 GitHub Pages 的 `/awesome-astra-3d/` 部署前缀。外站来源和原始下载保留原始地址。图片和视频加载失败时展示可见回退内容，保留来源与下载入口。

分页目录每页最多 36 条，提供上一页、下一页和所有页链接，覆盖全部 237 条记录；Astra 与参考内容分别标记。sitemap 包含首页与所有作品、专题和目录，共 497 个地址。

## 构建与发布集成

构建顺序为 catalog 同步 → Vinext 静态首页 → 独立静态页生成 → 导出校验。`scripts/verify-export.mjs` 检查页面 metadata、语言、部署子路径、本地资源、237 份完整 JSON、专题归属、分页覆盖及 sitemap 一致性。CI 在构建前运行 check 与 lint，在构建后按既有视频清单获取并核验完整播放版本。

没有新增依赖、后台、分析 SDK、模型 API 或外部发帖操作。ChatGPT / Sites 不部署；本轮发布目标仅为 GitHub Pages，发布和线上核查结果在 [04-测试](04-测试.md) 记录。

## 仓库介绍与复用资料

中英 README 使用同一组六件精选、材料路线及真实网站截图；自动统计和最新收录标记继续由生成脚本维护。`START_HERE.md` 把材料、第一步和小改练习置顶，已有长资料保留在进阶部分；新增英文指南及稳定 `blender`、`web`、`game` 锚点。

`docs/sharing/` 保存中英短介绍、三件作品文案、原创练习、署名拼图说明、掘金提纲和衡量方法。练习不冒充作者原始提示词；工程入口不等于全部工程已独立复现或可商业使用，完整视频仅表示原帖附带片段的全部时长。

## 偏差与回滚

实现沿用设计 B；未将独立页面改为 Vinext 动态路由。静态页由集中模板生成，降低 beta 路由及子路径部署的不确定性；首页交互和静态展示模板仍需在未来内容契约变更时共同验证。

回滚以一个相干 Git 提交恢复网站代码、生成脚本、索引及同版文档。生成器仅删除此前生成清单中不再存在的页面文件，并在删除前校验路径包含关系，不递归移除目录或无关文件。
