现有首页将三件精选藏在切换按钮后，长标题区和多排筛选占用较多高度；卡片中摘要、标签、证据、作者及多个入口同时展开，连续浏览时重复信息较多。改进重点是同时看到更多真实作品、稳定找到分类和材料入口。现有原作者归属、证据等级和详细过程继续保留。
