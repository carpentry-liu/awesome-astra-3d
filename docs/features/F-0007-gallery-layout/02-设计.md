# 方案与验收

视觉方向：深色三维作品展。保留墨黑与蓝色品牌，以真实作品、开放的留白和短标题形成层级。

方案 A：保留单图轮播，仅调整配色和按钮。改动少，但不能改善同时可见作品数量与多排筛选的占高。

方案 B（采用）：压缩导览区，三件精选同时展示；资源数量整合成一条导航；桌面分类及平台置于左侧，搜索、材料筛选和作品置于右侧。卡片保留大图、标题、作者、证据与直接材料入口，缩短重复摘要。手机分类继续横向浏览，内容按单列排列。

沿用现有 Tabs、Dialog、Input、URL 检索契约和数据文件；无新增依赖、账号、后台、第三方生成调用、访问统计或发帖功能。图库数据更新独立于展示，既有 141 条记录和历史视频保留。README 中英同步，以六图预览、快速导航和最新收录为前部，网站实拍与长说明可折叠查看。

新增 X 视频保存完整原平台版本。一个案例包含多个制作阶段时，为每段视频添加可选的标题，明确场景资产、三维预演和 H3 成片；无标题的历史视频保持现有显示。不得以同一作品的多个视频增加案例数量。

验收：数据与媒体清单一致，现有行为测试和 TypeScript、项目构建通过；实际浏览器检查桌面、手机、200% 放大、组合筛选、URL 回放、详情键盘关闭、视频播放及控制台。提供真实截图，验证 README 渲染。提交后更新 GitHub Pages 和原访问范围的 Sites；若出现问题，可回退本次独立提交与对应部署。
