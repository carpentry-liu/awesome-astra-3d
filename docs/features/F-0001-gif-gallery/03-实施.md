## 2026-11-12 自动播放调整

按用户补充要求，将首页 GIF 卡片、弹窗和独立详情改为默认自动播放。轻索引只增加原始 GIF 地址；原始案例、来源、媒体审计和首帧保持不变。列表新增停止 / 播放按钮，打开弹窗时暂停背景 GIF；React 与静态详情均监听系统减少动态效果偏好，允许用户主动播放。动图失败时回退首帧并提示，静态详情可再次尝试播放。原始 GIF 字节不变，未新增依赖。

## 2026-11-11 初次上线

2026-11-11，按 [设计](02-设计.md) 完成。

- `src/catalog.ts`、WebMCP 接受 `gif`；入口保留语言和传播参数、清除旧筛选。卡片索引不携带完整动图审计数据。

- 原生 GIF 元数据由 `scripts/gif-contract.mjs` 校验。双语静态页、目录、sitemap、README 及最新收录共同生成；导出检查验证原始链接与不自动播放约束。

没有新增依赖或生成 API。未修改历史案例与媒体记录。实现中为卡片采用真正的首帧而非空占位，使未播放时也能判断作品内容；该细节已回写设计。
