# 设计

关联 [R-0003](../../requirements/R-0003-gif-gallery.md)。

- `group=gif` 是独立集合；默认仍为 Astra。入口清除旧类别与资源筛选，但保留语言与传播参数。
- GIF 案例需 `animatedGif`：原始 URL、帧数、时长、尺寸、字节、SHA-256、核查日期；原始文件完整 GET、全部帧解码且至少两帧像素不同。作者声明与官方证据分级。
- 首页 GIF 卡片和详情默认自动加载原始 GIF，保持原始字节。列表提供统一停止 / 播放按钮，详情保留单件控制；停止恢复同一文件的首帧。首帧 JPEG 仍归档 Release，用于停止、减少动态效果和加载失败回退。系统减少动态效果时不自动播放，用户可主动开启；偏好变化时同步状态。静态作品页使用已有公共脚本提供相同默认行为，无 JavaScript 时仍有首帧和原文件链接。分页索引继续使用静态预览。
- 详情可打开原始 GIF，说明直接生成与录像转换的区别。统计中 GIF、Astra、方法参考三组独立；目录与 sitemap 覆盖全部记录。
- 不改变原有作品归属、不重新编码原始文件、不新增依赖或生成服务。原始第三方作品权利归作者。

风险：远程媒体可能失效，回退同一作品首帧并明确提示，保留回源入口。GIF 文件可能较大，列表沿用首批 36 条与图片懒加载，不批量获取全库原文件。README 使用原 GIF，保持链接回源与权利说明。

2026-11-12 自动播放调整比较：直接将事实源 `imageUrl` 换成 GIF 会破坏首帧与分享图契约，也失去可靠的停止回退。采用轻索引额外携带 GIF 原始地址，由展示层按播放状态切换；不加载完整审计信息。沿用现有 React 播放组件和静态公共脚本，不增加依赖、视频转码或生成服务。回滚时一并还原展示代码、轻索引生成物和本说明，原始案例与媒体无需更改。

验证：URL 往返、三组计数隔离、轻索引和完整数据一致、GIF 契约、静态页下载及按钮、旧链接与录像回归；`npm run check` / `npm run build`；宽屏、移动与窄屏真实截图、播放与控制台检查。按同一提交回滚代码、数据与生成物。
