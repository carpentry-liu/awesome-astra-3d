# 设计

关联 [R-0003](../../requirements/R-0003-gif-gallery.md)。

- `group=gif` 是独立集合；默认仍为 Astra。入口清除旧类别与资源筛选，但保留语言与传播参数。
- GIF 案例需 `animatedGif`：原始 URL、帧数、时长、尺寸、字节、SHA-256、核查日期；原始文件完整 GET、全部帧解码且至少两帧像素不同。作者声明与官方证据分级。
- 卡片使用原始 GIF 首帧，JPEG 预览归档 Release；播放保持原始 GIF 字节。交互页面提供点击播放 / 停止，停止时卸载动图并显示同一文件的首帧预览；不自动播放，尊重减少动态效果偏好。静态作品页使用已有公共脚本提供相同按钮；无 JavaScript 时仍有原始 GIF 链接。
- 详情可打开原始 GIF，说明直接生成与录像转换的区别。统计中 GIF、Astra、方法参考三组独立；目录与 sitemap 覆盖全部记录。
- 不改变原有作品归属、不重新编码原始文件、不新增依赖或生成服务。原始第三方作品权利归作者。

风险：远程媒体可能失效，继续提供回源与明确的加载失败提示；GIF 文件可能较大，仅用户点击后加载动画。README 使用原 GIF，保持链接回源与权利说明。

验证：URL 往返、三组计数隔离、轻索引和完整数据一致、GIF 契约、静态页下载及按钮、旧链接与录像回归；`npm run check` / `npm run build`；宽屏、移动与窄屏真实截图、播放与控制台检查。按同一提交回滚代码、数据与生成物。
