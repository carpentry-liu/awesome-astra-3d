# GIF 分类调研

2026-11-11 核查 [OpenAI 官方文档](https://developers.openai.com/api/docs/guides/image-generation#generate-animated-gif-output)：GPT-Image-2.6 Sunburst / Flare 支持直接输出 GIF。官方提灯猴子展示可直接获取的原始 GIF。公开作者展示页需进一步检查文件格式和帧内容；`.webp` 预览不等同于可下载原始 GIF。

当前 `group` 只有 Astra / reference，多处将非 Astra 记录统一计算成参考。新增分组必须同步 URL、WebMCP、首页统计、静态详情、目录、README 生成和数据校验。

方案一：作为 Astra 下的资源筛选。复用现有资源栏，但会把不同模型输出混进 Astra 数量，并使图像生成作品难以发现。

方案二（采用）：独立 `gif` 分组，首页和 README 提供入口，素材类别继续用于角色、产品、像素等题材。与 Astra 并列、单独统计。原始文件与逐帧审计使用可选 `animatedGif` 元数据，不依赖文件名猜测。沿用现有详情与外链预览，无新增依赖。
