方案 B（采用）：以作者材料为中心补充不同工具和题材，下载所收录 X 作品的完整视频，同步首页三件精选、README 六图、上手路线、About 和真实截图。保留现有深色图库、筛选、详情及移动布局，不重做视觉系统，不新增登录、追踪和投稿后台。

验证包括项目 check、lint、build，新增及旧记录完整性、图片和入口检查，真实桌面／手机截图、筛选与视频播放及控制台。GitHub Pages 与原 Sites 同步发布。回滚以本次独立提交为界，媒体归档不删除。
