# F-0002 分组设计

| 方案 | 影响 |
| --- | --- |
| Astra 目录增加模型标签 | 可保留四个标签页。现有 Astra 计数、默认检索、专题约束和分享地址需扩展，用户进入时需再选模型。 |
| 增加独立的 Fable 5.2 分组 | 复用 GIF 已验证的分组和筛选方式。新增稳定入口 `?group=fable#collection`，作品按既有 ID 生成中英详情和静态目录。 |

采用独立分组。以 `fable` 作为稳定 URL 和数据键，界面显示 Fable 5.2。公共分组键、校验、检索、只读 WebMCP 和构建生成器同步。首页保留 Astra 作为默认，新增首页直达入口和选项卡，README 增加可识别的精选成果与链接。四组分别显示计数。

新记录使用已有字段存放模型声明、来源证据和材料。模型声明须明确 5.2；混合工作流说明各方贡献。X 录像沿用完整原版与播放版 Release 资产，沿用现有播放逻辑和完整性验证。优先使用作者成果图，按记录保存归属和限制。

验证分组 URL、关键词和材料筛选、语言切换、旧入口、GIF 以及页面导出。宽屏和手机核查版面、控制台及新媒体播放。代码、数据和生成物按同一发布版本回滚。
