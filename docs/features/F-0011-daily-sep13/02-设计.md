# 设计

沿用现有三件精选、侧栏筛选与大图列表，不更换主题、依赖或数据结构。所有新增事实写入 data/cases.json，目录与统计由生成脚本计算。

1. 原作者作品图和结果视频海报用于卡片；输入参考不冒充输出。
2. 工具分工逐条说明，Astra 编排与其他模型生成资产分别归因。
3. X 附带视频下载最高码率与较小完整版本，核验时长、字节数、SHA-256 和全片解码。最高码率归档到独立 GitHub Release，较小版本经 Pages 提供播放；不裁剪或转码。
4. 更新三件首页精选、六图 README 和上手路线，使用新的桌面、案例区及手机真实截图。
5. 保留旧记录与旧链接检查日期。必跑 check、build，检查实际筛选、详情、手机溢出和浏览器控制台；发布后核对公开 JSON、README、截图及新增视频。

沿用既有 GitHub Pages 与 Sites 部署地址和访问设置，直接完成用户已授权的更新。
