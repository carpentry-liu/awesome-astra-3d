# 实施

## 实际交付

41 条数据：29 条 Astra 案例，12 条独立方法参考。官方逐页确认 12 条；其余来自独立作者网页、源码仓库、Reddit 和 X 原文转引。全部记录作者、模型标签、证据等级、输出类别、原始日期/观察日期、提示词公开情况、来源与素材权利。

数据与界面分离；主数据生成 Markdown 目录与公开 JSON。网站支持多词搜索、类别/来源交集筛选、参考分组、详情档案、深链接、复制与失败媒体回源。只读 WebMCP 工具复用同一筛选函数。

- Gogh Strike 使用自身仓库实机截图，梵高小镇仍保留无独立图片状态。

## 与设计的偏差

静态导出路径实际为 `dist/client`，已同步 hosting。采用静态构建所需的 Vinext / Sites 插件，不启用 Worker 开发模拟器。Windows Node 24.14 在预渲染完成后触发 libuv 退出断言；同源码切换 Node 22.22.0 后正常退出 0。构建脚本仅在受影响的 Windows Node 24+ 环境调用 npm 官方 Node 22 运行时，其他平台使用当前 Node。没有修改供应商源码、伪装退出码或强行更新锁文件依赖。

GitHub Pages 使用 Node 22.22.0 和仓库 basePath，Sites 使用根路径静态产物。所有第三方媒体仍为外部链接。
