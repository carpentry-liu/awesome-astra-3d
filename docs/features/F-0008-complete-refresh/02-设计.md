# 更新方案

方案 A：只替换首页图片和日期。成本低，但遗漏新作品、视频及旧入口状态，不符合整体更新要求。

方案 B（采用）：以案例事实源为中心，新增有来源的作品和视频；对公开预览、演示、项目、归档视频进行有界链接检查，再同步展示与文档。保留现有深色图库、三件精选、左侧分类和移动端布局，不引入后台、账号、统计追踪或新的检索状态。

新增记录保留作者、证据、模型分工、输出材料和许可边界；没有公开模型归属的线索不纳入 Astra 计数。X 视频保留原平台完整原片与完整播放版本，分别记录来源、时长和哈希。第三方作者已提供的 GitHub 视频优先回源，不为提高归档数量重复上传。

链接检查保存本次时间、HTTP 状态、最终 URL 和页面标题；超时、访问限制、登录页与明确 404 分开记录，单次异常不删除历史案例。页面中的未核实演示继续说明访问边界。

首页精选与 README 六图选择不同题材，全部来自所选作者的真实媒体。更新可见首页、案例区、手机截图，使用浏览器原生 JPEG 格式；截图不替代作者作品的来源图片。README 与上手路线通过同一批事实更新。

验证：运行项目 check、lint、build；实际浏览器检查宽屏／手机、新精选详情、关键词筛选、完整视频及控制台。核对新旧记录数量及历史保留，验证 Markdown 图片和部署后的数据、媒体地址。新页面和数据可按本次独立提交回滚，历史媒体保留。
