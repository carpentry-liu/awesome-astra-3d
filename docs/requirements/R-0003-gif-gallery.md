# R-0003 GIF 动图分类

2026-11-11 用户要求在当日更新中加入 GPT 新增的 GIF 生成功能与分类。

- 增加能分享、搜索、切换语言的 GIF 入口，并在中英文 README 展示真实成果。
- 明确 GPT-Image-2.6 与 GPT-6 Astra 的归属，分别统计；已有 Astra 录像或渲染 GIF 不因文件格式改变模型分组。
- 收录实际可获取、可解码的多帧 GIF，保留原作者、模型证据和原始下载地址；禁止把静态封面当动图。
- 原有筛选、独立详情、旧分享链接、录像归档和 GitHub Pages 子路径继续可用。
- 不接入生成 API，不添加运行服务，不部署 ChatGPT Sites。

方案与验证见 [F-0001](../features/F-0001-gif-gallery/01-调研.md)。
