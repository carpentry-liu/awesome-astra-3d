# 实施与审查结果

## 精简

- UI 从 60 个文件缩减到 Input、Tabs、Dialog 三个。删除 56 个不可达模板和通用 Button，将实际关闭按钮直接交给 BaseUI；删除无消费者的 hook、脚手架配置、导出和 22 个 CSS 选择器。
- 直接 / 开发依赖由 35 项缩减到 21 项，锁文件包记录由 699 条缩减到 275 条。保留的包版本和 integrity 未变化，没有新增包。保留对话框与 Tabs 使用的五个状态样式及动画依赖。
- 删除 Sites / Cloudflare 专用插件、类型和 hosting 配置。保留 Vinext 的 RSC 构建依赖和控制静态导出的 `next.config.ts`，统一 Node 最低版本为 22.22.0。
- 删除历史阶段日志、分享草稿、孤立覆盖快照与 114 张旧截图。长期设计和收录/下架规则归入 DESIGN 与维护说明，当前四张 README 实拍和分享封面保留。

合计删除 244 个已确认无必要的受控文件。删除是当前分支的文件清理；Git 历史保留，不进行强推或历史体积重写。

## 修复的 P2 问题

| 触发与影响 | 修改 |
| --- | --- |
| 普通作品弹窗未显示 `outcome`，Neural Sight 等案例的固定光照、采集缺口、视角与硬件限制不可见 | 增加“观察与局限”，与静态详情共用状态文案，保留作者原文及缺失语义 |
| 六条同时有摘录和任务摘要的案例只显示摘录，丢失工具准备与多轮上下文 | 同时显示短摘录与任务摘要，不改原始事实 |
| 播放地址只核验文件名后缀，错误目录也能通过检查，但发布文件实际只在 `videos/` | 数据与导出检查共用精确 URL 校验，交叉验证原版/播放版的案例、媒体与源帖关联 |
| `npm start` 指向不存在的 Worker 配置；启用首页路由中间件的预览又将静态详情重定向到 404 | 改为现有 Vite 静态预览，预览时停用 Vinext 路由插件，按多页 HTML 服务，未知文件返回 404 |
| lint 漏掉实际使用的组件、工具函数和配置，TypeScript 扫描却覆盖本地工作目录 | 扩展 lint 覆盖实际源码与配置，将类型检查范围收敛到项目 TS 文件 |

## 保留边界

285 条案例（273 Astra + 12 参考）、121 段完整录像、研究资料与三份来源审计均与清理前逐字节相同。保留 CATALOG、UPDATES、上手路线、贡献/权利说明、审核档案、双语详情、旧 `#case=`、URL 筛选和只读 WebMCP。

新增的两个共享模块同时具有实际消费者；不为了缩短文件而拆出无用抽象。公开 JSON、轻量索引与 sitemap 有当前调用方，不因派生属性被删除。所有删除都从显式 Git 跟踪清单执行，并检查绝对目标位于本项目。

详见 [实际验证](03-验证.md)。
