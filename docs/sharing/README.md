## 如何判断是否有帮助

每轮记录发布日期、主题、落地页和可取得的数据。比较相同长度的观察窗口，把“访问了什么”“开始使用材料”“新增收藏”分别记录；累计 Star 不能直接除以近 14 天访客计算转化率。

| 想知道的事 | 数据入口 | 当前边界 |
| --- | --- | --- |
| 仓库是否被发现 | GitHub Traffic 的浏览、独立访客、来源与热门路径 | 只覆盖仓库访问，窗口有限；不等于网站访问 |
| 教程是否被打开 | GitHub 热门路径中的 `START_HERE.md` / `START_HERE.en.md` | 未列出或读取失败记“不可取得”，不能填零 |
| 网站是否带来 GitHub 点击 | 将来如有明确授权，加入最小点击计数后再观察 | 目前没有点击埋点，这项数据不可取得；外链存在不等于发生点击 |
| 是否增加了 Star | 同一时区、同一时刻记录仓库 Star 总数，计算窗口内净变化 | 可能包含取消 Star；不能证明某一篇帖子导致增长 |

网站落地链接可以用 `utm_source`、`utm_medium`、`utm_campaign` 标识素材，例如：

[掘金 Blender 上手专题示例](https://carpentry-liu.github.io/awesome-astra-3d/topics/blender/?utm_source=juejin&utm_medium=article&utm_campaign=starter-2026-10)。参数用于区分链接，现阶段没有分析系统收集这些点击。

可使用以下记录模板，不可取得的数据保持缺失：

| 窗口 / 时区 | 素材与主题 | 仓库独立访客 | 教程入口浏览 | 网站 → GitHub 点击 | Star 起点 / 终点 / 净变化 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 待记录 | 待记录 | 不可取得 | 不可取得 | 不可取得 | 待记录 | 发布与核查日期、数据边界 |
